# T01 쉬운 답변 생성 — 결과 문서 작성 예시

> 이 파일은 새 평가 문서의 구성 예시입니다. 아래 E01의 판정 문구는 형식 예시이며, 실제 최종 점수로 사용하지 않습니다.

## 1. 테스트 개요

| 항목 | 내용 |
|---|---|
| 목적 | 정답 FAQ 1개가 제공된 상황에서 모델이 FAQ 내용을 정확하고 자연스럽게 재구성하는지 검증 |
| 평가 단위 | 질문 20개 × 모델별 답변 |
| 입력 | 사용자 질문 + 정답 FAQ Context |
| 기대 동작 | FAQ의 핵심 답변을 빠짐없이 전달하고, Context에 없는 내용을 추가하지 않음 |
| 제외/주의 | 검색(임베딩) 성능은 이 문서에서 평가하지 않음. 정답 FAQ가 이미 검색되었다고 가정 |

## 2. 평가 기준

| 기준 | 판정 방식 | 세부 기준 |
|---|---|---|
| 정확성 | 0~2점 | 0=핵심 결론 오류, 1=일부 부정확, 2=FAQ 핵심 사실과 결론 일치 |
| 완전성 | 0~2점 | 0=필수 정보 대부분 누락, 1=일부 누락, 2=질문에 필요한 정보 모두 포함 |
| 관련성 | 0~2점 | 0=무관/다른 질문에 답함, 1=불필요한 내용 혼입, 2=질문에 직접 답함 |
| 근거성 | 0~2점 | 0=Context 밖의 사실 추가, 1=일부 근거 불명확, 2=모든 사실이 Context로 확인됨 |
| 표현 자연스러움 | 0~2점 | 0=이해 곤란, 1=의미는 통하나 어색함, 2=자연스러운 상담 문장 |
| 환각 여부 | 예/아니오 | FAQ Context에 없는 사실·수치·절차·조건을 사실처럼 제시했는지 별도 기록 |
| 문제없음 | 예/아니오 | 환각을 제외하고 JSON 오류, 빈 답변, 형식 위반, 비정상 종료 등 문제가 없는지 기록 |

환각 여부와 문제없음은 서로 다른 게이트입니다. 환각은 근거성 점수와 연관되지만, 최종 판정에서는 별도 집계합니다. 이 문서는 레이아웃 확인용이므로 점수와 자원 수치는 임시값으로 표시합니다.

## 5. 케이스별 상세 판정

모델명을 열면 먼저 해당 모델의 질문·답변을 확인할 수 있고, 이어서 같은 모델의 질문별 평가표를 볼 수 있습니다. 아래 점수는 문서 모양을 확인하기 위한 임시값입니다.

#### 질문·답변

| 케이스 | 질문 | 모델 답변 |
|---|---|---|
| E01 | 해외 데이터 로밍 요금은 어떻게 되나요? | 해외 데이터 로밍 요금은 방문 국가와 선택하신 로밍 상품에 따라 다르게 적용됩니다. 구체적인 요금은 통신사의 로밍 상품 종류와 해당 국가의 데이터 이용 정책을 확인해 보시는 것이 가장 정확합니다. |
| E02 | 휴대폰을 분실하면 어떻게 해야 하나요? | 휴대폰을 분실하셨다니 안타깝네요. 가장 먼저 해야 할 일은 저희 고객센터에 즉시 분실 신고를 하시는 것입니다. 분실 신고 후에는 회선을 일시 정지하시는 것이 좋습니다. 이렇게 하면 추가적인 요금 발생을 방지할 수 있습니다. 필요하신 경우, 분실 신고 절차나 추가 지원에 대해 더 자세히 문의해 주시면 도와드리겠습니다. |
| E03 | 데이터 속도가 갑자기 느려졌어요. | 데이터 속도가 갑자기 느려진 것 같으시군요. 주로 데이터 제공량이 소진되었거나 네트워크가 혼잡해져 속도가 느려지는 경우가 많습니다. 현재 사용 중인 데이터 플랜의 잔여량을 확인해 보시거나, 주변 네트워크 환경이 다른 기기들과의 충돌 없이 원활하게 작동하고 있는지 살펴보시는 것이 좋을 것 같습니다. 만약 문제가 지속된다면 고객센터로 문의해 주시기 바랍니다. |
| E04 | 데이터 사용량을 확인하고 싶어요. | 현재 사용하신 데이터 양은 통신사 앱이나 웹사이트에서 제공하는 데이터 사용량 메뉴를 통해 확인하실 수 있습니다. 앱 내 '데이터 사용량' 또는 '통계' 섹션을 찾아보시고, 필요하시다면 고객센터로 문의하시어 자세한 내용을 확인하실 수도 있습니다. |
| E05 | 유심을 재발급받으려면 어떻게 하나요? | 유심 재발급을 위해서는 먼저 신분증을 준비해 주세요. 매장을 방문하시거나, 통신사의 온라인 서비스를 통해 신청하실 수 있습니다. 온라인 신청 시에는 통신사의 공식 웹사이트나 앱을 통해 진행하시면 됩니다. 자세한 절차나 필요 서류는 해당 플랫폼의 안내를 참고하시는 것이 좋습니다. |
| E06 | 번호를 변경하려면 어떻게 하나요? | 휴대폰 번호를 변경하려면 먼저 본인 인증을 완료한 후, 회사의 홈페이지, 고객센터를 통해 또는 가까운 매장을 방문하여 번호 변경 신청을 진행하시면 됩니다. |
| E07 | 이번 달 휴대폰 요금이 너무 많이 나왔어요. | 요금이 평소보다 높게 나왔다니 걱정되시겠네요. 먼저 최근에 데이터 사용량이 증가했거나, 로밍 이용 내역, 소액결제 내역, 그리고 추가된 부가서비스 이용 여부를 확인해 보시는 게 좋을 것 같습니다. 특히 데이터 사용량 증가나 부가서비스 가입이 요금 상승에 큰 영향을 미칠 수 있으니 그 부분들을 중점적으로 살펴보시는 것이 도움이 될 것입니다. 만약 확인 후에도 원인을 찾지 못한다면 고객센터로 직접 문의하시는 것도 좋은 방법입니다. |
| E08 | 약정 중 해지하면 위약금이 발생하나요? | 약정 기간 중 해지 시에는 위약금이 발생할 수 있습니다. 특히 할인이나 지원금을 받은 경우에는 계약 조건에 따라 위약금이 부과될 수 있으니, 구체적인 금액이나 조건은 계약 내용을 확인하시는 것이 좋습니다. |
| E09 | 현재 위치에서 가장 가까운 매장을 찾고 싶어요. | 현재 위치에서 가장 가까운 매장을 찾으시려면 위치 정보 제공에 동의해 주시면 됩니다. 동의하시면 자동으로 가장 가까운 매장을 추천해 드릴 수 있습니다. |
| E10 | 해외에서 데이터 로밍을 차단하고 싶어요. | 해외에서 데이터 로밍을 차단하려면 먼저 휴대폰의 설정 메뉴를 확인해 주세요. 대부분의 스마트폰에서는 '데이터' 또는 '로밍' 설정 옵션을 통해 로밍 기능을 비활성화할 수 있습니다. 만약 직접 설정이 어려우시다면, 통신사 고객센터에 연락하여 로밍 차단 서비스를 신청하는 방법에 대해 문의하시는 것이 좋습니다. 고객센터에서는 roaming 차단을 위한 추가 절차나 필요 서류 등을 안내해 드릴 것입니다. |
| E11 | 해외에서 데이터를 얼마나 썼는지 확인하고 싶어요. | 해외 로밍 사용량 확인은 앱이나 통신사 홈페이지의 로밍 이용 내역 페이지에서 가능합니다. 해당 페이지에서 최근 사용한 데이터량을 확인하실 수 있습니다. 자세한 내용이나 추가 도움이 필요하시다면 언제든지 고객센터에 문의해 주세요. |
| E12 | 유심을 잃어버렸는데 새로 발급받고 싶습니다. | 유심을 잃어버렸을 때 재발급을 원하신다니 안타깝네요. 신분증을 준비하시고, 가까운 통신사 매장을 방문하시거나 온라인으로 재발급 신청이 가능합니다. 온라인으로 신청하시려면 통신사의 공식 웹사이트나 앱을 통해 진행하시면 됩니다. 매장 방문 시에는 직접 신분증을 제시하여 절차를 밟으시면 됩니다. 자세한 절차나 필요 서류에 대해 더 알고 싶으시다면 고객센터로 문의하시는 것도 좋은 방법입니다. |
| E13 | 휴대폰을 바꾸면 번호도 바뀌나요? | 네, 기기만 변경하실 경우 기존의 전화번호는 그대로 유지됩니다. 번호 변경은 요금제 변경이나 서비스 이용 조건 변경 등 다른 상황에서 이루어질 수 있으니, 구체적인 변경 사항이 궁금하시다면 고객센터에 문의하시는 것이 좋습니다. |
