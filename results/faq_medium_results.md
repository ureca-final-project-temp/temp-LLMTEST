# FAQ Medium 테스트 결과

> 상태: **미실행 (템플릿)** — 모델 실행 후 표를 채워 넣습니다.
> 평가 방법론 전체는 [`README.md`](../README.md) 참고. 이 문서는 항목 1(답변 정확도)·2(RAG 충실도)·5(표현 품질)·6(명령 수행 능력)·7(성능)만 다룹니다.
> `사람 평가(의견)` 컬럼은 LLM Judge와 별개로, 각 결과를 직접 확인한 사람(운영자)의 의견을 적는 칸입니다. Judge와 의견이 다르면 사람 판단을 최종으로 합니다.

## 개요

- 데이터: `data/eval_sets/faq_medium.csv` (10건, Test ID `M01`~`M10`)
- 난이도 특징: 질문이 구어체·상황 묘사로 표현되어 FAQ 문구와 직접적인 키워드 일치가 적음 — 의도 추론이 필요한 케이스. 일부(M07)는 정답 FAQ가 2개인 복합 질문
- 전제: 정답 FAQ(Ground Truth FAQ)는 임베딩 검색이 이미 올바르게 찾아줬다고 가정하고, 그 FAQ 원문 + 사용자 질문을 LLM에 그대로 제공한 뒤 생성된 답변만 평가. 정답 FAQ가 2개인 케이스는 두 FAQ 원문을 모두 제공

## 채점 기준 (컬럼 설명)

| 컬럼 | 의미 | 판정 방식 |
|---|---|---|
| 답변 정확도 | FAQ 핵심 정보를 빠짐없이 담았는가 | LLM Judge (O/X 또는 1~5점) |
| RAG 충실도 | FAQ 원문에 없는 내용을 추가하지 않았는가 | LLM Judge (O/X) |
| 환각 내용 | 충실도 위반 시 구체적으로 어떤 문장이 근거 없는지 | LLM Judge (텍스트) |
| 표현 품질 | 자연스러움·명확성·친절성(한국어 품질 포함) | LLM Judge (1~5점) |
| 포맷 성공 | 지정 출력 형식을 지켰는가 | 결정론적 (스키마 검증) |
| Latency | 응답 1건당 소요 시간 | 계측 (ms) |
| TPS | 초당 생성 토큰 수 | 계측 |
| 사람 평가(의견) | 사람이 직접 확인한 의견 (Judge와 별개, 최종 판단 기준) | 사람 (자유 텍스트) |
